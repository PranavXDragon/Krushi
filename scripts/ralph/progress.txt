# Codebase Patterns
- Backend: FastAPI + SQLAlchemy SQLite + WebSocket at /ws/telemetry.
- Cryptography: SHA-256 recursive chaining (CryptoEngine), canonical JSON key sorting.
- Offline-First: Monotonic sequence increment (Seq_i = Seq_{i-1} + 1) with local queuing and idempotent MQTT burst ingestion.
- Frontend: React 19 + TypeScript + Vite + Tailwind CSS + Lucide + Recharts.
- Visualization: Multi-compartment reefer truck mapping in TruckOverlay.tsx.

- **Learnings:**
  - Hardcoded or simulated signatures in prototype code can be seamlessly converted to true ECDSA (SECP256k1) signatures using compact 64-byte `(r, s)` hex representation.

  - Database relative pathing in SQLite must be anchored with `__file__` to ensure test runners and application servers access the identical database regardless of invocation directory.
